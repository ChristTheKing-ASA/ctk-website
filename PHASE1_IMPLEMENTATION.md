## 🔧 Troubleshooting

### "Module not found: Can't resolve 'resend'"
**Solution**: Run `npm install`

### "RESEND_API_KEY is not defined"
**Solution**: 
1. Make sure `.env.local` exists (not `.env`)
2. Add `RESEND_API_KEY=re_your_key`
3. Restart dev server

### "Failed to send email"
**Solution**:
1. Check Resend API key is correct
2. Try using `onboarding@resend.dev` as EMAIL_FROM
3. Check Resend dashboard for error logs
4. Verify you haven't exceeded free tier (3,000 emails/month)

### "Database not found"
**Solution**:
1. Run `npx wrangler d1 create ctk-website-db --local`
2. Run `npm run db:migrate`
3. Restart dev server

### "Emails going to spam"
**Solution**:
1. Verify your domain in Resend dashboard
2. Add DNS records (SPF, DKIM, DMARC)
3. Use your verified domain as EMAIL_FROM
4. For testing, `onboarding@resend.dev` works fine

### "Admin dashboard shows no submissions"
**Solution**:
1. Check database was created and migrated
2. Submit a test form
3. Check browser console for errors
4. Verify D1 binding in `wrangler.toml`

## 📊 Database Schema

### contact_submissions
```sql
CREATE TABLE contact_submissions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT,
  subject TEXT NOT NULL,
  message TEXT NOT NULL,
  status TEXT DEFAULT 'new',
  ip_address TEXT,
  user_agent TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  responded_at DATETIME,
```
